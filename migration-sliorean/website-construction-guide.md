<!--more-->

🤔博客第一篇，我想写一下我的建站过程，也希望可以给其他想建站的人一点启示。

## 为什么选择Hexo + GitHub Pages？

在众多博客搭建方案中，我选择了 **Hexo + GitHub Pages**，原因如下：

- ✅ **完全免费**：无需购买服务器和域名
- ✅ **简单易用**：Markdown写作，一键部署
- ✅ **访问速度快**：GitHub Pages全球CDN加速
- ✅ **可定制性强**：丰富的主题和插件

## 前期准备

- 一台联网的电脑

- 一个GitHub账号（我直接用Google账号登陆的）

- 一双灵活的手

- 一个聪明的小脑袋瓜O(∩_∩)O
